# Cassino Pros
Aplicativo Android para gerenciamento de banca e sessões de jogos de slot.
Stack: Kotlin, Jetpack Compose, Material 3, Android SDK.
Primeira base: dashboard, banca, sessões e resultado rápido.
Próximas etapas: Room, descoberta/abertura de apps de cassino instalados, slots, histórico, estatísticas, limites, metas, segurança biométrica, backup, widgets e testes.
